// Requirements

Before you start

Xcode 26 or newer

The design layer uses the iOS 26 glassEffect symbol, so the project compiles with the Xcode 26 SDK.

iOS 17.0+ at runtime

Runs on iPhone and iPad. Liquid Glass lights up on iOS 26; older versions fall back to a material surface.

Clone, open, run

1

Clone the repository

$ git clone https://github.com/sahilramani/Tabs.git
$ cd Tabs
2

Open the project in Xcode

$ open Tabs.xcodeproj

No dependencies to install — Tabs is pure SwiftUI, SwiftData, Vision, and PDFKit. There's also a Makefile with make run and make test shortcuts if you prefer the command line.

3

Pick a target and run

Select an iPhone simulator or a connected device, then press ⌘R. The app launches straight to the home screen with an empty subscription list, ready for your first import.

⚠️

Simulator note: Vision OCR returns no text on a blank simulator photo library. Test the screenshot path with a real statement image, or use the PDF path — there are sample statements in samples/.

// First run

Your first import

The fastest way to see Tabs work is to feed it one real statement. Here's the whole loop.

01

Tap the + and choose a source

Scan a screenshot of your bank app, import a PDF statement, or pick a folder of statements. More months of history gives better detection.

02

Let it allow notifications

Grant the local notification permission so Tabs can remind you before a renewal. It's the only system permission the app asks for, and it never leaves your device.

03

Review the detected charges

Tabs proposes what looks recurring. Edit names, prices, and billing cycles, deselect anything that isn't a subscription, then save the rest.

04

See your real monthly spend

Saved items land on the home screen with everything normalized to a monthly figure — and a reminder scheduled for each renewal.
