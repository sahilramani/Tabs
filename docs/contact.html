Let's talk on GitHub.

Tabs is open source and developed in the open. Bugs, ideas, and questions all live on GitHub — where the conversation stays public and searchable for everyone.

Report a bug

Something not detecting right, a crash, a layout glitch? Open an issue with your steps and what you expected — the more detail, the faster the fix.

Open an issue ↗

Ask a question

Not sure how something works, or want to talk through an approach? Start a thread in Discussions — questions, ideas, and show-and-tell all welcome.

Open Discussions ↗

Request a feature

Have an idea — a brand that isn't detected, a cycle Tabs should infer, an export you want? File it as an issue describing the problem you're trying to solve.

Suggest a feature ↗

Contribute code

Adding a brand to the detector is a one-line change, and there's room for much more. Read the contributing guide, then open a pull request.

Read CONTRIBUTING.md ↗

Reporting safely

Tabs collects nothing, so there's no account data to worry about. When you file an issue, please never attach a real bank statement or screenshot with personal financial details — redact amounts and account numbers, or recreate the problem with the sample statements in the repo. Public issues are visible to everyone.
